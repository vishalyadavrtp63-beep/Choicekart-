FIREBASE SETUP

1. Firebase Console me project create karo.
2. Web App add karo.
3. Firebase Authentication me Email/Password enable karo.
4. Firestore Database setup karo.
5. Firebase Storage setup karo.
6. Firebase Console se Web App ki configuration values copy karo.
7. firebase-config.js me YOUR_API_KEY, YOUR_AUTH_DOMAIN, YOUR_PROJECT_ID,
   YOUR_STORAGE_BUCKET, YOUR_MESSAGING_SENDER_ID aur YOUR_APP_ID ko
   Firebase ki exact values se replace karo.

IMPORTANT:
Abhi Firebase configuration values change nahi karni hain.
